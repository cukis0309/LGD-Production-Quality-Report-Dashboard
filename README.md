## 📖 설명

이 프로젝트는 **LG디스플레이 직무 이해 및 생산·품질 업무 실습**을 목적으로 제작한 교육용 웹서비스입니다.

사용자는 조회하고 싶은 **기간과 생산라인(A/B/전체)**을 선택하여 생산 및 품질 데이터를 확인할 수 있습니다.

주요 생산·품질 지표는 다음과 같습니다.

* 목표 생산수량
* 실제 생산수량
* 생산 달성률
* 검사수량
* 불량수량
* 불량률
* LOT별 생산·검사 기록
* 날짜별 불량률
* 생산라인별 설비 사건

### 생산 달성률

```text
생산 달성률 = 실제 생산수량 ÷ 목표 생산수량 × 100
```

### 불량률

```text
불량률 = 불량수량 ÷ 검사수량 × 100
```

검사수량이 `0`인 경우 불량률은 계산하지 않고 **판단 불가**로 표시합니다.

## 🏭 주요 기능

### 1. 생산·품질 데이터 조회

시작일, 종료일, 생산라인을 선택하여 해당 조건의 생산 데이터를 조회할 수 있습니다.

조회 결과에 따라 다음 정보가 자동으로 변경됩니다.

* 생산량 / 목표량
* 생산 달성률
* 검사수량 / 불량수량
* 불량률
* LOT별 생산 기록
* 설비 사건 기록

---

### 2. LOT별 근거 데이터 확인

조회 범위에 포함되는 LOT의 정보를 표 형태로 확인할 수 있습니다.

| 항목  | 설명          |
| --- | ----------- |
| 일자  | 생산 및 검사 일자  |
| 라인  | 생산라인 A 또는 B |
| LOT | 생산 LOT 번호   |
| 목표  | 목표 생산수량     |
| 생산  | 실제 생산수량     |
| 검사  | 검사 완료수량     |
| 불량  | 불량수량        |

---

### 3. 날짜별 불량률 시각화

조회된 생산·검사 데이터를 기반으로 날짜별 불량률을 계산하고 막대그래프로 표시합니다.

이를 통해 특정 날짜의 품질 이상 여부를 빠르게 확인할 수 있습니다.

---

### 4. 설비 사건 관리

생산라인에서 발생한 교육용 설비 사건을 조회할 수 있습니다.

예시:

* 설비 정지
* 온도 주의
* 정상 복귀
* 미해제 이상 상태

설비 사건은 생산 데이터와 별도로 관리하여 보고서 작성 시 근거 자료로 활용합니다.

---

### 5. Three.js 3D 생산 설비

Three.js를 이용하여 패널 검사·이송 설비를 3D로 구현했습니다.

3D 설비에는 다음 요소가 포함되어 있습니다.

* 금속 프레임
* 롤러 컨베이어
* 패널
* 투명 검사 커버
* 검사 카메라
* 검사 스캔 영역
* 작업자 모니터
* 상태 표시등
* 조명 및 그림자

마우스를 이용하여 설비를 자유롭게 확인할 수 있습니다.

```text
마우스 드래그 : 설비 회전
마우스 휠     : 확대 / 축소
시점 초기화   : 기본 카메라 위치로 복귀
```

---

### 6. 현재 모의 설비 상태

조회된 과거 생산 실적과 현재 모의 설비 상태를 구분하여 표시합니다.

예를 들어,

```text
라인 A : 정상 / 28°C
라인 B : 온도 주의 / 42°C
```

전체 라인을 선택한 경우 대표 3D 설비는 **라인 A**를 표시합니다.

---

### 7. 생산·품질 보고서 자동 생성

조회한 생산·품질 데이터를 근거로 업무 보고서 초안을 생성할 수 있습니다.

보고서에는 다음 정보가 포함됩니다.

* 조회 기간
* 생산라인
* 생산수량
* 목표수량
* 생산 달성률
* 검사수량
* 불량수량
* 불량률
* 조회된 LOT 개수
* 설비 사건
* 현재 모의 설비 상태
* 추가 확인 사항
* 검토 메모

보고서 생성 이후 조회 조건을 변경하더라도 기존 보고서의 근거 데이터는 변경되지 않도록 구성했습니다.

---

### 8. 보고서 검토 및 저장

생성된 보고서 초안을 사용자가 직접 수정하고 검토할 수 있습니다.

검토 후

```text
조회 범위·수치·사건·표현을 근거와 대조했습니다.
```

항목을 체크하여 검토 여부를 기록할 수 있습니다.

---

### 9. 보고서 다운로드

저장된 보고서는 다음 형식으로 다운로드할 수 있습니다.

```text
TXT  : 업무 보고서 본문
JSON : 보고서 생성에 사용된 근거 데이터
```

보고서 번호는 다음과 같은 형식으로 자동 생성됩니다.

```text
R001
R002
R003
...
```

---

### 10. Cloudflared 외부 접속

Google Colab에서 Flask 서버를 실행한 뒤 Cloudflared Tunnel을 생성합니다.

실행이 완료되면 다음과 같은 임시 외부 접속 주소가 생성됩니다.

```text
https://xxxxx.trycloudflare.com
```

해당 주소를 이용하면 Colab 외부의 PC나 모바일 브라우저에서도 웹서비스에 접속할 수 있습니다.

## 🚀 실행 방법

Google Colab에서 Python 코드를 실행합니다.

실행 과정은 다음과 같습니다.

```text
1. Flask 설치 확인
        ↓
2. Three.js / OrbitControls 준비
        ↓
3. Flask 웹 서버 실행
        ↓
4. 생산·품질 데이터 및 API 구성
        ↓
5. Cloudflared 실행
        ↓
6. 외부 접속 URL 생성
        ↓
7. 웹 브라우저에서 대시보드 실행
```

Cloudflared 주소는 Colab 런타임을 다시 실행할 경우 변경될 수 있습니다.
